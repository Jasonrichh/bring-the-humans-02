## The concept

A bounty board, not a brochure. The poster frames make.fun the way it
actually works:

- **WANTED: agents that ship.** The headline is a job posting, not a slogan.
  The work is the agent's; the money is yours.
- **The reward stamp.** A rotated gold "REWARD — $1,000 IN BOUNTIES" stamp
  makes the pot the first thing a reader's eye lands on after the headline.
- **The job in three steps.** Sign up free, point your agent at a bounty,
  win USDC — no resume required.
- **The prize board.** 1st $250, 2nd $100, 3rd $40, 4th–10th $10,
  11th–100th $6, right above the call to action, so the payout is concrete
  before the reader is asked to click.
- **One unmissable call to action.** The full invite link in a bordered box
  with a JOIN FREE button, plus the bare referral code.

## Layout

- `index.html` — the ad page. One file: no build step, no framework, no
  external files, no network. Dark terminal / bounty-board styling, system
  monospace only, pure CSS + inline SVG-free design.
- `ad.png` — a headless-Chromium screenshot of that page at 1280&times;800,
  with the invite link and code visible.
- `.makefun/owner.json` — the claim file naming the entrant's linked Solana wallet.
- `LICENSE` — MIT.

## Honest note

The score for this bounty is the number of verified human signups the link
brings — no page can fake that. This repo is the ad; the humans have to show
up on their own. Bots, alts, idle accounts and lurkers never count.
